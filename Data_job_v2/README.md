# Data Jobs Dashboard w/ Power Bi
![Project 1 Dashboard](../images/Project2_image1.PNG)

## Introduction

Exploring the data job market can be overwhelming due to the volume of scattered information available. This interactive dashboard (V2.0) was created to support **aspiring data professionals, career switchers, and job seekers** by simplifying that complexity.

Built using a real-world dataset of 2024 data job postings—including details such as job titles, salary ranges, and locations—this project delivers a clean, single-page dashboard that enables users to quickly analyze market trends and gain clear insights into compensation patterns

## Skills Demonstrated

### Dashboard Design
 - Built a streamlined, intuitive one‑page layout focused on clarity and usability. 
 - Organized visuals to highlight key metrics and trends without overwhelming the user.
### Power Query (ETL)
- Extracting, cleaning, transforming, and shaping raw data.
- Applying best practices for efficient and repeatable data preparation.

### Data Modeling
- Building scalable data models using star-schema principles.
- Defining relationships and ensuring optimized model performance.

### DAX Fundamentals
- Writing calculated columns and measures to support analytical logic.
- Implementing aggregations, KPIs, and business rules.

### Visualizations Used
- **Core Charts:** Bar, column, line, and area charts for comparisons and trend analysis.
- **Map Visuals:** Displaying geographic insights.
- **Cards:** Highlighting KPIs and summary metrics.
- **Tables:** Presenting detailed, structured data.
- **Additional Visuals:** Selecting the most effective chart types for clear storytelling.

### Interactive Features
- **Slicers:** Enabling dynamic filtering and user-driven exploration.
- **Buttons & Bookmarks:** Enhancing navigation and creating guided report experiences.



## Dashboard Overview

This second iteration **consolidates the dashboard into a single, focused page** designed to give job seekers the most essential market insights at a glance.


![Dashboard Page 1](../images/Project2_image1.PNG)

This page serves as a concise command center for exploring the data job market. It highlights key KPIs including **Job Count, Skills Per Job, Median Yearly Salary, and Median Hourly Salary**. The dashboard also provides quick insight into **Skill Popularity** (by job percentage or count) and enables easy comparison of salaries across different job titles, offering an efficient high‑level overview.


## Conclusion

This updated Version 2.0 dashboard demonstrates how Power BI can turn large volumes of job‑posting data into a streamlined, insightful career analysis tool. It supports Job Seekers, Job Transitioners, and Job Swappers by allowing them to filter and explore essential market insights on a single page, helping them make confident and informed career decisions.
